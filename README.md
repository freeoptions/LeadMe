# LeadMe

面向 Android 的个人离线交通示意图。以家为原点，用直线道路、独立地铁出口和公交站台记录相对位置，不使用真实地图或定位。

## 当前交付状态

按需求文档第一版范围编写了应用源码、资源、基础工程描述和测试源码。**尚未编译、运行自动化测试或进行 Android 真机验证，不能视为已验收的安装包。**

## 已编写的功能

- 首次创建住所、查看只读示例；示例不会写入个人数据或进入备份。
- 多住所创建、重命名、切换、归档、只读查看及恢复；不提供住所删除或复制。
- 家固定在世界坐标 `(0, 0)`；北向上，画布平移、双指缩放和以家居中的全图适配。
- 直线道路的临时放置、端点调整、整体移动、删除。
- 地铁站分组、批量出口、单独添加和修改出口、整站删除；最后一个出口删除时同步清理空站。
- 独立公交站台，包含名称、方向和备注；不记录线路编号。
- 按缩放显示名称，出口图标不聚合；查看模式可点击完整详情。
- 草稿编辑、一次性保存、整轮取消、连续撤回；拖动每次只形成一条撤回记录。
- 拖动时第二根手指加入，取消未完成的对象修改，再转为视口操作。
- 道路吸附默认关闭，按屏幕距离捕获道路、保持侧别，并高亮候选道路。
- Room 本地存储，整图保存和整批导入均使用事务，归档图拒绝写入。
- 系统文件选择器导入导出 UTF-8 JSON；导入前预览，生成独立副本、重建 ID、处理名称冲突。
- 系统浅色/深色主题、语义化地点节点、至少 48dp 的地点命中区域。

## 数据与生命周期

表单“应用到草稿”、新增、删除和拖动均不访问数据库。只有整图保存、住所管理和确认导入会正式写入。保存事务失败时仍保留当前草稿与撤回栈。

草稿、撤回栈、视口及页面入口保存在 ViewModel 中，表单文本使用 `rememberSaveable` 保留配置变化状态。进程结束后只读取最后一次正式保存的数据，不实现跨进程草稿恢复。

数据库版本为 1，不使用破坏性迁移。首次在构建环境运行 KSP 后应保留生成的 Room schema；后续升级必须增加明确迁移并验证旧数据保留。

Manifest 不申请网络、定位或文件管理权限。系统自动备份及设备迁移规则排除个人数据；厂商具体行为仍需真机验证。手动备份为明文，不包含示例、视口或未保存内容。

包名为 `com.leadme.app`。后续交付只使用 release 构建，并使用固定正式签名保持升级兼容；源码中不包含签名密钥。
